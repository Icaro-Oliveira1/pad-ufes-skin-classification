Justificativa Imputar seria leak mascarado
  • Ma & Zhang (NeurIPS 2021): MNAR não é identificável — mesmo com infinitas amostras, a imputação fica enviesada
  • Sisk et al. (2023): missing indicators em outcome-dependent missingness são harmful
  • MICE, missForest, KNN → todos criam assinatura detectável como proxy do diagnóstico
Sinal biológico real (fotótipo, diâmetros) será recuperado via PDI da imagem.
Decisões-chave do pipeline
  • Zero imputação — após drops, dataset fica 100% completo
  • Split por patient_id — evita vazamento entre fotos da mesma lesão
  • fit_transform só no treino — ColumnTransformer do sklearn impede leak por construção
pipeline sklearn · fit-on-train · reproduzível

03
Segmentação
Otsu no LAB L*
Isola a lesão. Fallback automático quando Otsu falha.
04
Crop + resize
bbox quadrada, 256×256
Padding 10%. Preserva aspect ratio — não distorce assimetria.
Otsu (1979) — threshold binário automático
  • No canal L* do LAB, histograma dermatológico é bimodal: pico de pele clara + pico de lesão escura
  • Otsu varre 256 valores e escolhe o que maximiza a variância entre os dois grupos
  • Zero treinado, ~5 ms por imagem, interpretável — não exige dataset nem GPU
maximiza σ² = ω₀·ω₁·(μ₀ − μ₁)²
Qualidade da segmentação
  • 2298 / 2298 imagens processadas, zero erros
  • 1.5% fallback total (35 imgs) — muito abaixo do 5–10% típico
  • MEL 3.8% fallback — apenas 2/52, 96% dos melanomas segmentados
Output do pipeline
  • 2298 × .npz contendo {image 256×256×3, mask 256×256}
  • 326 MB cacheados em disco · reuso ~5 ms/img
  • Helper: load_processed(img_id) → (image, mask)

PARTE 5 · MODELAGEM
09 / 12
Família de árvores — progressão de complexidade

DT → RF → XGBoost · cada nível agrega

Modelo 1 — Decision Tree
Árvore única · sem ensemble. RandomizedSearchCV (30 iter × CV=5, F1-macro). Melhor: max_depth=10, criterion=gini.
Serve como piso de comparação — mostra o custo de não ter ensemble.
Modelo 2 — Random Forest
Bagging: N árvores independentes + votação. Melhor: n_estimators=300, max_depth=10, max_features=sqrt.
A diversidade entre árvores cancela erros individuais.
Modelo 3 — XGBoost ★
Boosting: cada árvore corrige erros da anterior. Melhor: max_depth=3, lr=0.05, n_estimators=200.
Árvores rasas + correção iterativa → melhor generalização.
Desbalanceamento: class_weight='balanced' na DT e RF · sample_weight equivalente no XGBoost. Dataset intacto — os 33 MELs continuam 33.

PARTE 7 · CONCLUSÕES
12 / 12
PAD-UFES-20 · pipeline completo · nb01 → nb08

O que aprendemos · limitações e próximos passos

Resultados principais
✅
Progressão DT → RF → XGBoost confirmada. Cada nível de ensemble trouxe ganho real em F1-macro — a hierarquia esperada se verificou nos dados.
✅
XGBoost: F1-macro 0.604 · Recall MEL 0.400. Boosting com árvores rasas (max_depth=3) generalizou melhor. Features clínicas dominam — bleed, changed, age no top 3.
✅
CNN (imagem pura): Recall MEL 0.600. Sem nenhuma feature clínica, a rede aprendeu representações visuais que as 62 features handcrafted não capturam. Os dois modelos são complementares.
✅
PDI contribui, mas não domina. 8 features PDI no top 20 do XGBoost — glcm_correlation e lab_a_std validados empiricamente pelo MI ranking.
Limitações
⚠
N de MEL é pequeno demais para certeza estatística. 33 no treino · 10 no test. Uma predição muda o recall em 10 pp. Resultados indicam tendência, não conclusão definitiva.
⚠
Dependência da anamnese. Performance dos modelos clássicos cai se metadados estiverem ausentes ou imprecisos — bleed, changed, age dominam o sinal.
⚠
Espaço de busca do RF limitado. max_depth baixo não foi explorado — o RF pode ter ficado abaixo do seu potencial real.
Próximos passos naturais
→ Mais dados de MEL — único caminho para superar a limitação estatística
→ CNN + tabular (fusão tardia) — combinar os dois paradigmas
→ Calibração de threshold por classe — aumentar recall MEL sem perder F1 geral
